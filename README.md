# Inventario Local POS

Sistema de Punto de Venta (POS) e inventario web desarrollado con Flask y PostgreSQL. Diseñado para ser rápido, compatible con lectores de códigos de barras y adaptable a dispositivos móviles como PWA (Progressive Web App).

## Tecnologías Utilizadas
* Backend: Python 3, Flask, PostgreSQL, Gunicorn
* Frontend: HTML5, CSS3, JavaScript Vanilla, Service Workers

## Despliegue en Railway
Este proyecto está configurado con un `Procfile` y variables de entorno estándar para ser desplegado automáticamente en la plataforma Railway.
